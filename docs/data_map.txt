3. ARTIFACT SEMANTICS
======================================================================

RAW

Answers:
What market bars were persisted?


HISTORICAL MANIFEST

Answers:
What exact audited historical dataset do those bars represent?


DECISIONS

processed/decisions/

Per-bar strategy/runtime explanation.

Answers:
What did the system see and decide?


TRADES

processed/trades/

Closed-trade ledger.

Answers:
What complete trade lifecycles actually closed?


REPORTS

processed/reports/

Derived analytics.

Not primary runtime truth.


RESEARCH

processed/research/

Reproducible campaign, diagnostic, entry-quality, universe and other
scientific artifacts.

These are not generally disposable.


Preferred interpretation order:

runtime:
decisions → trades → reports

historical data:
raw → manifest → HistoricalResearchSource audit

research:
manifest → source fingerprints → trials/candidates → aggregation → conclusion

9. BATCH EXECUTION PRINCIPLE
======================================================================

Research Universe V1 is one data-preparation mission.

Do not process symbols manually one by one.


The reusable batch workflow should:

1. load the frozen universe definition
2. recognize BTC/ETH as already complete
3. backfill each missing symbol
4. recover legitimate source gaps
5. build each historical manifest
6. validate each source
7. record fingerprints and audit statistics
8. record failures without discarding successful work
9. resume safely
10. emit one universe-level qualification artifact


Batch execution must be:

- deterministic
- restartable
- idempotent where practical
- provenance-preserving
- failure-aware

======================================================================

The old rule that deleting data/processed/* is broadly safe is OBSOLETE.

- canonical historical datasets

- universe qualification artifacts

======================================================================

approximately 54–59 bytes per stored 5-minute bar.

approximately 0.017 GiB per symbol.

Disk is therefore not the current universe-size constraint.

API acquisition time, evidence quality and market relevance matter more.
