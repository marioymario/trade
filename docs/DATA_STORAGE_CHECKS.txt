- where project data lives
- which disks/mounts back it

This is an operational reference.
It is not mission-specific.
It should stay useful over time.

--------------------------------------------------
3) CORE CHECKS
--------------------------------------------------

A) Check filesystems, free space, mounts, and devices

cd ~/Projects/trade

echo '=== FILESYSTEMS ==='
df -h

echo
echo '=== MOUNTS (interesting) ==='
mount | egrep '/home|/mnt|/media|Projects|trade|archive'

echo
echo '=== BLOCK DEVICES ==='
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS

What this tells you:
- available space
- active mount points
- whether a second disk is mounted
- what device backs each mount

--------------------------------------------------
4) PROJECT SIZE CHECKS
--------------------------------------------------

B) Check total project size and top-level usage

cd ~/Projects/trade

echo '=== PROJECT SIZE ==='
du -sh .

echo
echo '=== TOP-LEVEL SIZES ==='
du -sh ./* 2>/dev/null | sort -h

echo
echo '=== DATA TREE SIZES ==='
du -sh data data/* data/processed/* 2>/dev/null | sort -h

What this tells you:
- total repo size
- which top-level directories are large
- how much data/ is contributing

--------------------------------------------------
5) RAW VS PROCESSED BREAKDOWN
--------------------------------------------------

C) Check raw and processed data usage

cd ~/Projects/trade

echo '=== RAW BREAKDOWN ==='
du -sh data/raw data/raw/* data/raw/*/* data/raw/*/*/* 2>/dev/null | sort -h | tail -n 50

echo
echo '=== PROCESSED BREAKDOWN ==='
du -sh data/processed data/processed/* data/processed/*/* data/processed/*/*/* 2>/dev/null | sort -h | tail -n 100

What this tells you:
- whether raw or processed artifacts are the main storage driver
- which subtree is growing

--------------------------------------------------
6) CANDIDATE LARGE STORAGE PATHS
--------------------------------------------------

D) Check likely archive/storage locations

echo '=== CANDIDATE LARGE STORAGE PATHS ==='
du -sh /mnt/* /media/* /home/kk7wus/* 2>/dev/null | sort -h | tail -n 50

find /home/kk7wus /mnt /media -maxdepth 3 \( -iname '*archive*' -o -iname '*data*' -o -iname '*disk*' -o -iname '*storage*' \) 2>/dev/null

What this tells you:
- where other storage-heavy directories may already exist
- whether archive paths live outside the repo
- whether the large mounted disk is actually being used

--------------------------------------------------
7) DAILY RAW PARTITION CHECKS
--------------------------------------------------

E) Check raw daily partitions and estimate daily/weekly size

cd ~/Projects/trade

echo '=== RAW DAILY PARTITIONS ==='
find data/raw -type d -name 'date=*' | sort

echo
echo '=== RAW DAILY SIZES ==='
find data/raw -type d -name 'date=*' -print0 | xargs -0 du -sh | sort -h

Focused BTC/USD 5m version:

cd ~/Projects/trade
find data/raw -type d -path '*/BTC_USD/5m/date=*' -print0 | xargs -0 du -sh | sort

What this tells you:
- exact daily partition sizes
- rough weekly cost
- whether raw data growth is stable or changing
